# Codex project instructions

Before starting any task in this repository, read the entire
[shared project rules](.github/copilot-instructions.md) and follow all of them.
The instructions in that file apply to Codex throughout this repository, including
its mandatory workflow, approval requirements, invariants, and completion requirements.

`.github/copilot-instructions.md` is the single source of truth for the project
rules shared by GitHub Copilot and Codex. Keep the rules there rather than
duplicating them here, so both tools use the same rules when they change.

Resolve the referenced path relative to this repository root, even when working
in a subdirectory.
